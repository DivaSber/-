# Умный Чемодан (PWA)

Это готовый код для публикации приложения на GitHub Pages. 

## Как опубликовать:
1. Зарегистрируйтесь на [GitHub](https://github.com/) и создайте новый репозиторий (например, `smart-suitcase`).
2. Загрузите в этот репозиторий все файлы из этого архива:
   - `index.html`
   - `sw.js`
   - `manifest.json`
3. **Важно:** Добавьте в репозиторий две картинки для иконки приложения:
   - `icon-192.png` (размер 192x192 пикселя)
   - `icon-512.png` (размер 512x512 пикселей)
4. Перейдите в **Settings** (Настройки) репозитория -> вкладка **Pages**.
5. В разделе **Source** (Build and deployment) выберите ветку `main` (или `master`) и нажмите **Save**.
6. Через пару минут ваше приложение будет доступно по ссылке формата `https://[ваш_ник].github.io/smart-suitcase/`.

Зайдите по этой ссылке с телефона, и браузер предложит установить приложение на главный экран (Add to Home Screen).
