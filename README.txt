ПРИЛОЖЕНИЕ "УМНЫЙ ЧЕМОДАН" (PWA для iPhone и Android)

Как запустить и установить на iPhone:
1. Загрузите все файлы из этой папки (index.html, manifest.json, sw.js, icon-192.png, icon-512.png) на любой бесплатный хостинг с поддержкой HTTPS (например, Netlify, Vercel или GitHub Pages). Либо откройте через локальный сервер.
2. Откройте полученную ссылку в браузере SAFARI на iPhone.
3. Нажмите кнопку "Поделиться" (квадрат со стрелочкой вверх внизу экрана).
4. Прокрутите меню и выберите "На экран «Домой»".
5. Нажмите "Добавить".

Готово! Приложение появится на рабочем столе вашего iPhone и будет работать в полноэкранном режиме.
